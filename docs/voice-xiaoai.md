# 方寸接入小爱同学

方寸可以先使用小爱同学应用里的训练计划作为安全入口，不需要开放平台账号。训练计划只负责打开方寸并预填内容，必须由用户在方寸中确认后才会写入，避免其他应用伪造深链批量修改数据。中文内容仍由方寸现有的智能识别器处理。

## 配置训练计划

1. 在手机上打开小爱同学应用，进入训练计划或自定义指令，新建一条指令。
2. 设置唤醒短语，例如“记录日程”或“打开方寸记录”。
3. 添加执行动作，选择“打开网址”或系统提供的同类动作。
4. 填写 `fangcun://voice?text=` 模板；需要固定短语时可填写 `fangcun://voice?text=记录日程`。保存后试运行一次，首次运行时请选择由方寸打开。
5. 保持方寸安卓壳已经登录。深链带有固定文字时，方寸会预填快捷输入框；检查内容后点击“智能识别”并确认添加。`text` 留空时只聚焦快捷输入框。

可以为少量固定短语分别建立训练计划，例如：

- `fangcun://voice?text=记录日程`
- `fangcun://voice?text=记录待办`
- `fangcun://voice?text=打开今日安排`

方寸设置中的“语音助手（小爱同学）”可以生成或重置专用语音令牌，并查看最近 50 条服务器语音命令。令牌只在生成或重置时显示一次；重置后旧令牌立即失效。该令牌用于以后接入经过审核的小爱开放平台 HTTPS 中转，不应放进训练计划 URL，也不要发送给其他人。网页中可以撤销某条命令创建的内容。

## 能力边界

消费级小爱同学训练计划只能打开静态网址方案，不能把对话里的日期、时间或事项名称动态填入 `text` 参数。因此“明天下午三点交材料”这类动态内容需要在方寸快捷输入页补全，或为少量固定口令分别建立训练计划。方寸不会把静态模板描述成动态语音槽位。

安卓公开的系统闹钟接口只允许写入并预填小时、分钟和名称，不能读取、修改或删除用户已有闹钟，也不能精确指定某个日历日期。为了避免远期事项在错误日期响铃，只有未来 24 小时内的提醒才会打开系统时钟供用户确认；更远的日期自动使用方寸原生精确通知。部分系统会忽略预填参数，这是正常的系统差异。关闭方寸中的闹钟模式不会删除已经保存到系统时钟的闹钟。

## 米家与音箱进阶路线

需要音箱直接理解动态参数、家庭成员区分或设备联动时，需要在小爱开放平台创建技能，并用服务端适配器把平台请求转换为 `POST /api/voice/command`。服务端已具备独立令牌、每用户数据隔离、频率限制、命令记录和撤销基础，但小爱平台请求/响应适配、账号绑定和审核仍需要在取得开发者账号后完成，不能把通用 API 描述成已经审核上线的小爱技能。
